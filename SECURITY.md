# Security and privacy reports

This repository should never contain real save files, full logs, account identifiers, access tokens, IP addresses, personal absolute paths, or another person's data.

If you discover exposed personal data, a credential, or instructions that could enable unauthorized access, do not reproduce the material in a public Issue. Contact the maintainer privately through the security-reporting channel configured on the GitHub repository. Until private vulnerability reporting is configured, report only that a private disclosure is needed, without including the sensitive material.

This project documents a defensive, local recovery workflow. Reports involving competitive cheating, online economies, anti-cheat bypass, DRM circumvention, unauthorized access, or server-side manipulation are out of scope.
