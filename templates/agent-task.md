# 给本地 AI Agent 的任务模板

将方括号内容替换后使用。第一轮只授权读取和复制，不授权覆盖、删除或同步。

```text
目标：调查并尝试恢复我拥有的本地单机游戏数据。

游戏与平台：[游戏名、Steam/GOG/其他]
事故描述：[例如云端旧版本覆盖了本机新版本]
事故大约发生时间：[时间和时区]
希望恢复到：[时间点，或等级/任务/地点等可观察状态]
涉及设备：[本机、另一台电脑等]
当前状态：[游戏和启动器是否退出、云同步是否关闭]

第一阶段仅允许：
1. 读取与目标游戏明确相关的目录、日志和元数据；
2. 建议需要扩大的搜索范围，但扩大前先说明理由；
3. 将证据复制到新的保全目录；
4. 生成包含相对路径、大小、修改时间和 SHA-256 的清单；
5. 建立事件时间线和候选版本表。

第一阶段禁止：
- 覆盖、删除、移动或改名任何原文件；
- 启动游戏或启动器；
- 开启云同步、上传或下载；
- 修改注册表、存档内容或文件时间；
- 无边界扫描与本任务无关的个人目录；
- 上传原始存档或日志到外部服务。

输出时请明确区分：已证实事实、合理推断、未知项。为每个候选版本列出支持证据、反对证据、风险和验证办法。完成只读调查后停止，等我确认具体写入方案。
```

## 写入阶段追加授权模板

只有在看过证据报告并选定候选后再发送：

```text
我授权测试候选：[候选编号及来源]

执行前请：
1. 再制作一份当前工作目录的可回滚副本；
2. 明确列出将被替换的文件及其来源；
3. 保持云同步关闭；
4. 只做最小替换，不删除未知文件；
5. 写入操作日志并给出一键回滚步骤。

写入完成后停止，由我启动游戏并人工验证。未经我再次确认，不要启用云同步或继续测试其他候选。
```
